# ShopPulse E-Commerce SQL Analytics Project

A structured end-to-end SQL project built on a relational database (`customers`, `products`, `orders`).

##  Key Features & SQL Skills Demonstrated
- **Database Schema Design:** Primary Key, Foreign Key constraints, and Data Integrity.
- **Data Manipulation & Filtering:** CRUD operations, pattern matching (`LIKE`), set filtering (`IN`).
- **Multi-Table Joins:** 2-Table and 3-Table `INNER JOIN` queries for order fulfillment reports.
- **Business Aggregations:** `GROUP BY` and `HAVING` clauses for category-wise revenue & metrics.
- **Advanced Analytics:** Subqueries and Window Functions (`ROW_NUMBER() OVER`) for product ranking.

##  Repository Structure
- `shoppulse_analysis.sql` - Complete SQL script containing table schemas and analytical queries.
